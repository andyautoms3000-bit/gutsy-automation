## Deploy
Upload the contents of this folder to the page directory in the Gutsy Automation GitHub Pages repository. The entry page is `index.html`; keep the `assets/` directory beside it.

The navigation links point to:
- https://gutsyautomation.com/
- https://gutsyautomation.com/solutions
- https://gutsyautomation.com/store
- https://gutsyautomation.com/about
- https://gutsyautomation.com/onboarding

## Screenshots
The supplied Guava Clip application screenshot is installed at `assets/images/guava-clip-dashboard.png` and configured as the `tool-dashboard` screenshot.

To add or replace other screenshots:
1. Put the image in `assets/images/`.
2. Open `assets/clipping-guide.json`.
3. Update the relevant `src` path and optional `alt`, `caption`, and `description` values.
4. Commit and push both files.
